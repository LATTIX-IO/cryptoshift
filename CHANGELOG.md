## [0.1.0] - Candidate only, not published

### Added

- Versioned, bounded cryptographic inventory, typed dependency graphs, iterative SCC topology and evidence-qualified risk analysis.
- Explicit post-quantum target profiles, sourced vendor capabilities and conservative peer/PKI compatibility analysis.
- Prerequisite-linked remediation, nonauthorizing migration-wave proposals and immutable, digest-bound advisory plans.
- Cryptoshift-owned neutral inventory and policy fixture handoff, E2 Linux/Windows conformance and frozen hostile regression corpus.
- Atomic analysis facade with privacy-bounded diagnostics, reproducible scaling harness and clean-room packaged Cargo consumer.
- Manual candidate SBOM, source identity metadata and pinned GitHub provenance attestation, without registry publication.

### Security

- Preserve unknown evidence as Partial, prohibit silent algorithm downgrade, fail closed on wrong tenant, forged content pins and exhausted budgets.
- Reserve Complete/Warnings runtime results until independent capability and approval verification (FOSS-513).
- Leave publish = false and existing release safety guard enabled; administrative GitHub ruleset correction (FOSS-509) remains a release prerequisite.

### Limitations

- No native upstream Cryptomap/Cryptopolicy wire interoperability, real peer or PKI trust verification, authenticated change-control approval or migration execution.
- Version 0.1.0 is a proposed artifact identity, not evidence that the crate was published or approved for production.
