# cryptoshift

The `cryptoshift` crate is part of the Lattix open-source ecosystem.

This crate currently provides development-only Rust contracts for inventory,
immutable graphs, explainable risk, approved target and capability profiles,
evidence-bound peer, protocol and PKI compatibility, and non-executing blocker
and remediation analysis, bounded nonauthorizing SCC wave drafts, and immutable migration plan proposals
with source-pinned residual risk and unverified exception claims.
It does **not** yet
produce a complete migration plan, authenticate external cryptographic proofs,
or authorize infrastructure changes. It remains unpublished; the first public
release requires separately approved release work (FOSS-456).

Repository: https://github.com/LATTIX-IO/cryptoshift
